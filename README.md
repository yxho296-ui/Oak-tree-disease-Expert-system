# Oat Wilt Disease Expert System

## Overview

This project is a rule-based expert system designed to identify potential oat wilt disease based on user-selected symptoms. The system uses a predefined knowledge base implemented in JavaScript to simulate decision-making and provides possible diagnoses along with recommended treatments.

This project demonstrates classical artificial intelligence concepts, specifically rule-based reasoning and knowledge-based systems, implemented in a simple web application.



## Features

- Symptom-based disease diagnosis
- Rule-based inference system (IF-ELSE logic)
- Instant prediction output
- Treatment and prevention recommendations
- Simple web-based user interface



## Tech Stack

- HTML – structure of the application
- CSS – styling and layout
- JavaScript – core rule-based logic and inference engine


  
## How It Works

1. Users select symptoms from the interface.
2. The system evaluates inputs against a predefined knowledge base.
3. Each rule maps a combination of symptoms to a specific disease condition.
4. When a match is found, the system returns:
   - Predicted disease
   - Recommended treatment or solution

This approach simulates an expert system using deterministic logic rather than machine learning.
